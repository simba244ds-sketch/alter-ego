# Публикация ALTER EGO

## Готовый артефакт

`npm run build:web` выполняет `expo export --platform web` и создаёт `dist/`. Expo Router настроен на `web.output: static`; экспорт содержит `index.html`, `identity.html`, `conversations.html`, `catch-up.html` и локальные ассеты. Интерфейс и функции для публикации не менялись.

## Vercel — основной вариант

В `vercel.json` указаны сборка, `dist/` и `cleanUrls: true`. Маршруты `/identity`, `/conversations`, `/catch-up` обслуживаются соответствующими HTML-файлами. Параметр `?id=platform` выбирает диалог на клиенте. Не требуется переписывать все запросы на `index.html`.

Нужен подключённый аккаунт Vercel с правом создания проекта и production-деплоя. В текущей среде интеграция Vercel не установлена, переменных Vercel и локальной авторизации нет. Не вводите токен в чат; подключите интеграцию Vercel через каталог плагинов/приложений и выполните авторизацию там.

После подключения: создать проект, собрать текущие исходники, выполнить production-деплой, убедиться, что Deployment Protection не требует входа у демонстрационных посетителей, и проверить выданный HTTPS-адрес в чистой браузерной сессии.

## Netlify — резервный вариант

`netlify.toml` задаёт ту же сборку и `dist/`, а также прямое обслуживание трёх маршрутов через соответствующие HTML-файлы. Нужен подключённый аккаунт Netlify с правом публикации. Интеграция Netlify в текущей среде также не установлена и локальная авторизация отсутствует.

## Данные и переменные

Демонстрационная версия использует seed из `src/data/seed.ts`, сценарный mock AI из `src/services/mockAI.ts` и локальное хранилище браузера. Реальные корпоративные сведения и backend API не подключены. Для сборки не нужны переменные окружения или секреты. Изменения каждого посетителя остаются в его браузере, между посетителями данные не синхронизируются.

## Проверка публичного деплоя

1. Без cookies, bearer-токенов и входа получить HTTPS 200 для `/`, `/identity`, `/conversations`, `/catch-up` и `/conversations?id=platform`.
2. Проверить прямое открытие и reload каждого адреса; отсутствие 404 и перенаправления на авторизацию.
3. Проверить 390×844 и 1440×1000: режимы присутствия, пять узлов, сохранение настроек, AI-черновик, перехват и ссылки Catch-up.
4. Проверить загрузку JS, шрифтов и SVG, отсутствие ошибок консоли и горизонтального переполнения.

Публичный URL пока не получен. Локальный сервер и временный предпросмотр не являются опубликованным приложением. Публикация и проверки публичного URL заблокированы отсутствием подключённого аккаунта хостинга.
