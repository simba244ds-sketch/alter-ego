# Правила разработки ALTER EGO

## Процесс

Сначала PRODUCT.md и SPEC.md; затем Expo, токены/компоненты, Presence/Identity, Conversations/Catch-up, проверка. Поддерживать документы в соответствии с фактическим поведением. Не выполнять деплой без отдельного запроса.

## Стек и структура

React Native + Expo + TypeScript strict; Expo Router; StyleSheet и токены; Zustand persist + AsyncStorage. `app/`, `src/components/`, `src/theme/`, `src/domain/`, `src/data/`, `src/services/`, `src/store/`. Промежуточные файлы и браузерные проверки в `work/`.

## Ограничения

Не блокироваться из-за API-ключей. Только mock AI и локальные сообщения. Явная маркировка каждого AI-сообщения. aiAllowed задаётся независимо от грейда, UI не может расширять права. Перехват отменяет возможность публикации старого AI-запроса. Для неполучивших разрешение каналов AI недоступен. Не добавлять auth, push, production backend или сложную анимацию за счёт сценария.

## UI

Токены — единственный источник палитры. Mobile-first 390×844; поддерживать web и native средствами React Native. Нажатия, поля, загрузка, ошибки и пустые состояния осмысленны. Собственная графика по визуальному направлению референсов. Русский интерфейс с допустимыми продуктовыми терминами Alter / Identity / Catch-up.

## Проверка

1. `npm run typecheck`.
2. Проверить доменные сценарии: грейд не выдаёт права, перехват и устаревший запрос, подтверждение AI-черновика.
3. `npx expo export --platform web` и запуск `npm run web`.
4. В браузере проверить навигацию, пять узлов, сохранение после reload, генерацию/черновик, перехват, поиск, фильтры и переходы из сводки.
5. Проверить 390×844 и широкий экран, отсутствие ошибок консоли и горизонтального overflow.
6. В README указать запуск, ограничения и выполненные проверки. Не заявлять проверку iOS/Android, если запускался только web.
